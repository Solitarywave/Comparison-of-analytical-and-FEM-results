Instructions (Fig.10)

1. Run "Fig10_FEM.m".
2. Wait until the computation is complete.
3. From the Mesh and Solve menus in the PDETool window:
   - Select Export Mesh and export the mesh.
   - Select Export Solution and export the solution.
   - Do not change the default variable names when exporting.
4. Run "Fig10_Analytical_vs_FEM.m".
5. The script plots the head profile for \beta = 0.04 m^-1 and compares the analytical and FEM results.

Input Parameters

Any changes to the FEM input parameters can be made through the PDE Specification menu in PDETool.
